# Add Player Names to Round Extremes Table

### Who

<!--Who does this benefit or who will this affect? Who should be able to view this?-->

- Users viewing the Sjoelen General Statistics page

### What

<!--What problem needs addressing?-->

- The Round Extremes table on the Statistics page shows the highest and lowest scores for each round, but does not show which player achieved those scores
- Users have no way of knowing who holds the round records

### Why

<!--What value does this add?-->

- Adds recognition for players who achieved record round scores
- Makes the statistics more meaningful and engaging
- Allows friendly competition over round records

### Acceptance Criteria

<!--Testable done conditions; avoid implementation detail.-->

- [ ] The Round Extremes table displays the player name alongside each highest score
- [ ] The Round Extremes table displays the player name alongside each lowest score
- [ ] If multiple players share the same extreme score, all player names are shown
- [ ] The table remains readable and well-formatted with the additional information
